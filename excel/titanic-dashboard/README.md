# Titanic Survival Analysis Dashboard

## Overview

This project is an interactive data analysis dashboard built in Microsoft Excel using the Titanic dataset from Kaggle. The dashboard provides insights into passenger demographics and survival patterns through key performance indicators (KPIs), PivotTables, Pivot Charts, and interactive slicers.

The dashboard enables users to explore survival trends based on passenger class, gender, age group, family size, and fare category, making it easier to identify the factors that influenced survival aboard the Titanic.

> **Note:** This project was independently designed and developed using the Titanic dataset from Kaggle as part of my learning journey in Excel data analysis and dashboard development.
