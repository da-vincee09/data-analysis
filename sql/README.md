# SQL Projects

This directory contains my SQL data analysis portfolio, showcasing projects focused on querying, transforming, analyzing, and extracting meaningful insights from structured data using PostgreSQL.

## Overview

The projects in this folder demonstrate practical SQL skills commonly used in data analytics and reporting. They cover the data analysis workflow—from exploring and transforming data to answering business questions and generating actionable insights.

Most projects are developed using **PostgreSQL** with **pgAdmin** as the database management and development environment.

## Skills Demonstrated

* Data Exploration
* Data Cleaning and Preparation
* Data Transformation
* Data Analysis
* Exploratory Data Analysis (EDA)
* Data Aggregation
* Business Reporting
* KPI Analysis
* Trend Analysis
* Comparative Analysis
* Ranking Analysis
* Business Insights

## SQL Features Used

* SELECT Statements
* Filtering and Sorting
* Aggregate Functions
* GROUP BY and HAVING
* JOINs
* Subqueries
* Common Table Expressions (CTEs)
* CASE Statements
* Window Functions
* RANK and DENSE_RANK
* ROW_NUMBER
* LAG and LEAD
* Date and String Functions
* NULL Handling
* Conditional Logic
* Data Type Conversion

## Folder Structure

Each project in this directory will typically include:

* SQL scripts (`.sql`)
