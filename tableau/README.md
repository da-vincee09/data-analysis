# Tableau Projects

This directory contains my Tableau data visualization portfolio, showcasing projects focused on transforming raw data into interactive dashboards and guided data stories.

## Overview

The projects in this folder demonstrate practical Tableau skills commonly used in business intelligence and analytics reporting. They cover the complete data visualization workflow—from data preparation to presenting actionable insights through interactive, multi-dashboard workbooks and narrative-driven stories.

## Skills Demonstrated

- Data Cleaning and Preparation
- Data Analysis
- Exploratory Data Analysis (EDA)
- Dashboard Development
- Data Visualization
- KPI Reporting
- Business Reporting
- Data Storytelling
- Trend Analysis

## Tableau Features Used

- Calculated Fields
- Custom Chart Types (lollipop, treemap, heatmap, packed bubble, scatter, bullet-style)
- Dashboards
- Filter & Highlight Actions
- Parameters
- Stories
- Table Calculations
- Data Blending & Shaping (split/pivot)
- Interactive Dashboards

## Folder Structure

Each project in this directory will typically include:

- Packaged Tableau workbook (`.twbx`)
- Project documentation (`README.md`)
- Dataset (when available)
- Dashboard/story screenshots
- Link to the published Tableau Public viz

This folder is continuously updated as I complete new Tableau projects and expand my data analysis portfolio.
